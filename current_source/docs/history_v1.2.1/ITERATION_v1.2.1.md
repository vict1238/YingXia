# 映匣 v1.2.1

本次调整播放工作台的离开与返回行为，精简粘贴入口。v1.2.0 的搜索访问检查、排序、进度与取消行为继续保留。

## 播放状态

- 从播放工作台切到搜索影片、收藏与记录或来源与诊断时，内置 video/HLS 自动暂停，保留播放器和当前位置。
- 返回工作台后保持暂停；点击“播放所选集”继续当前视频。选了其他集数或线路后仍按新选择播放。
- 网页播放器通常是跨站 iframe，宿主页无法可靠调用其播放器暂停接口。离开工作台时移除 iframe，结束该页面播放；返回后手动打开所选集。
- 离开时取消尚未完成的播放启动。已经发出的解析请求或 HLS 回调即使稍后返回，也不能在其他页面继续自动播放。
- 自动下一集只在工作台处于播放状态时触发；离开工作台后不启动下一集。
- 停止仍释放播放资源，并恢复空状态。

## 窗口结构

`main.go` 的 `openApp` 启动已安装的 Edge/Chrome，传入 `--app=<本机服务地址>` 与 `--user-data-dir=<应用数据目录>/browser-profile`。因此当前是浏览器应用模式窗口：Go EXE 运行本机 HTTP 服务，HTML/CSS/JavaScript 作为界面，现有浏览器提供窗口与视频解码能力。若未找到适用浏览器，会回退系统默认浏览器打开本机地址。

本次不迁移桌面窗口技术；是否采用 WebView2 或其他桌面容器，等待用户下一步指示。

# 项目归档说明

本仓库导入当前 Windows／Android 2.3、历史 WebView 1.3.2、原生 2.0 与 Python 原型的源码、锁文件、依赖源码、构建脚本、许可证、研究记录和验证报告。

已发布安装包和源码压缩包保持原文件名和原字节，分别放在对应 GitHub Release；每版包含更新说明和 SHA-256 清单。全部原始附件的路径、大小和摘要见 [release-assets.json](release-assets.json)。原始交接文档与旧清单按历史记录保留，其路径和版本号描述当时状态。

原项目没有可导入的 Git 提交历史，因此本次统一导入完整项目，版本标签定位该归档提交。历史版本的精确源码使用其 Release 附件中的原始源码包。当前两端的发布源码包也保留在 2.3.0 附件中。

公开目录排除本机工具链、编译缓存、临时测试二进制、重复解包目录、签名私钥与密码、本机账户和播放数据，以及原始 HTTP 抓取目录；保留必要的生产 AAR、Gradle wrapper、WebView loader、图标资源及带来源和许可证的上游源码归档。排除项不影响原始交付文件，原项目目录未修改。

发布前核对了全部现有校验文件，并检查公开源码与发布源码归档中的密钥、访问令牌和会话信息。原生组件、规则、字体与再发行运行库的许可证和来源沿用各项目的第三方说明。

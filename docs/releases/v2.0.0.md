# 映匣 v2.0.0 · Windows／Android 原生版

- 推出 Flutter 原生 Windows 窗口与独立 Android APK，使用 libmpv 原生播放器，保留四页布局、来源更新和搜索访问检查。

Windows x64 单 EXE；Android 8.0+ 通用 APK。原生播放器需要直接或静态解析得到的媒体地址。

# 映匣 v2.2.0 · 来源管理、测速与独立超分默认值

- Windows 与 Android 统一扩展为47 个内置来源：30 个筛选 CMS、16 个 Kazumi 规则与1 个既有目录；上游更新后数量可变化。
- 来源管理加入搜索、筛选、分页、自定义 CMS 增删改、启停、单源／批量测速、进度与取消，并保留上游更新及用户设置。
- 超分启动默认改为关闭，显式下次启动默认值与临时播放选择独立；旧版临时轻量档迁移为关闭。
- Android 移植该版业务功能，加入实际 Surface 输出核实、设备能力回退与系统文档保存窗口导出诊断。

Windows x64；Android8.0+，包含 ARM64／ARMv7／x86_64，可覆盖同签名旧版。

Windows30 项 Dart、8 项同哈希实际窗口及12 项生产传输检查；Android49 项 Dart 和正式 APK／合成 HLS 安装运行检查通过。各后台有14 项引擎、5 个子例及1 项生命周期测试。Android GPU 探针条件与正式配置分别记录；ARM 真机、耗电和核显持续性能未测。

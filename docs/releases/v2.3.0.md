# 映匣 v2.3.0 · 断点续播、缓存与播放区控件

- 加入 HLS 明确标记广告跳过、有限提前缓存、卡顿换源提示，以及核对作品／年份／季数／当前集数后继续播放。
- 收藏和历史支持断点续播，接近片尾或已完成时从同集开头重播；清空历史同步清除断点并保留收藏。
- 播放区／全屏原生控制条整合音量、倍速、超分、画面比例、快进快退和缓存设置；搜索支持拼音、首字母与中文近似片名联想。
- Android 加入长按画面临时2 倍速、电视启动入口、方向键焦点与大屏控制条。
- 媒体转发修复长响应超时与截断，采用有上限的包／分片缓存；继续保留来源管理、测速、更新和启动默认超分关闭。

Windows x64；Android8.0+ 三 ABI，同包名同签名覆盖更新。

Windows56 项、Android75 项 Flutter 测试与静态分析通过；后台最新源码在 API35 x86_64 模拟器完成37 项引擎、15 子例和1 项生命周期测试，生产 Windows 传输29 项检查通过。最终 Windows 窗口和 Android 安装包有实际记录；Windows 新 fixture 后台启动受系统应用控制阻止，未计为通过。MatePad Pro／Android16／物理 ARM 与 TV 持续性能未测。

广告处理依赖 HLS 的明确标记，未标记与烧录进画面的广告无法保证识别。AES128 且 EXT-X-VERSION:1 的改写兼容性尚未单独实测；详细范围见原验证报告。

# 更新记录

## 1.0.0 — 2026-10-10（首个源码运行版）

- 内置目录搜索、详情、全部来源组和手动选集。
- 支持腾讯、爱奇艺、优酷、B站和芒果的静态入口检索与播放页导入。
- 接入既有八项来源配置；HLS 默认关闭；没有标成已实播通过。
- 目录播放器、媒体直连、七条平台解析适配；逐集平台绑定。
- 保留英文完整标题和季数，支持中文数字，不把 B站 ep 编号当作集数。
- 目标来源缺集时要求重新选择，不静默回退第一集。
- 收藏、历史、网络许可、来源开关和脱敏诊断导出。
- 默认独立 Edge / Chrome 配置；本机 API 会话与 CSRF 防护。
- 播放请求序号防止停止后被较慢的旧请求重新打开。
- 自生成离线演示；源码、回归测试、Windows 启动及可选构建脚本。

未完成：第三方实播验收、Windows 真机与 EXE 构建验收、全平台动态目录/完整选集协议。

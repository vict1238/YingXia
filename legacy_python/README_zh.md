# 映匣 YingXia v1.0

**本包是可运行源码版，不是已经编译、签名并通过 Windows 验收的 EXE。**

Python 负责本机后台，Edge / Chrome 负责独立应用窗口与网页播放。
不需要 Tampermonkey，不需要安装 pip 运行依赖。

## 1. 先启动，再试功能

1. 将压缩包完整解压到普通目录，例如 `D:\YingXia_v1.0`。不要直接在压缩包内运行。
2. 电脑需要 Python 3.10+；推荐已安装的 64 位 Python 3.12 / 3.13。官方下载页：
   https://www.python.org/downloads/windows/ 。安装时勾选 Add python.exe to PATH。
3. 双击 `START.bat`。默认查找 Edge，再查找 Chrome，使用单独浏览器配置打开应用窗口。
   优先用 Chrome 可双击 `START_CHROME.bat`。找不到两者时，退回默认浏览器普通标签页。
4. 先点击「先试试离线演示」。选第一季，点击「播放所选集」；可换集、收藏、查看记录。
   两段短片都是自生成的色条测试，不是电影，也不是在线片源成功证据。
5. 使用完点击左下角「退出软件」。运行期间保留后台命令行窗口；关闭它会停止服务。
   只关浏览器窗口而忘记退出时，后台在停止收到页面心跳约 5 分钟后退出。

程序只监听 `127.0.0.1` 的一个随机空闲端口，不需要对公网开放端口。
不要直接双击 `yingxia/web/index.html`；那样没有 Python 后台，搜索和设置无法运行。

## 2. 在线目录：内置片名搜索 → 作品 → 选集 → 播放

在搜索框输入片名，保留准确季数，例如「某剧 第二季」。
搜索方式选择「无损云目录」，首次操作确认第三方网络提示。
查询使用原脚本的联想搜索与详情接口；联想失败时尝试同一目录的详情搜索。

点击候选时核对片名、年份、电影/剧集类型和简介。**同名结果不自动合并或自动播放。**
选择右侧来源组及集数，然后点击「播放所选集」。
默认「目录网页播放器」会将目录返回的媒体地址交给无损云网页播放器。
「媒体直连」使用浏览器原生视频能力；不保证原生支持所有 HLS / 编码 / DRM。

软件保留目录返回的全部 `$$$` 来源组，但不承诺这些组实际可播。
换组时只匹配明确的集名或自然集数；目标组没有对应集，就要求手动选择。
不会因为缺集而偷偷播放第一集。

**在线目录只有一条，不是“全网所有电影随便搜”。**
第三方接口返回空结果、验证页或错误时，会显示原因，不混入演示片伪装成功。
接口的分页、返回条数和片库覆盖仍由来源决定；v1.0 不进行无边界全库抓取。

## 3. 腾讯、爱奇艺、优酷、B站、芒果的入口与七条解析线路

这里有两条不同的路径：

### 路径 A：尝试平台入口检索

搜索下拉框选择具体平台。程序尝试从官方公开搜索页提取带标题的播放链接。
这是**静态 HTML 检索实验功能**，不能保证取得动态加载内容、准确同名版本或完整选集。
结果只是候选，必须核对。不突破平台验证、登录或会员授权。

未取得结果时，可以点击「打开官方搜索」，进入具体某一集播放页，复制地址。
然后在软件右上角选择「粘贴平台播放页」。导入后只会生成“当前播放页”一项，
不会伪造全剧集数。换集需要对应新播放页。

### 路径 B：已有平台播放页直接导入

右上角粘贴 HTTPS 播放页，可选填作品名称。导入本身不发送网络请求。
选中来源后，在「播放方式 / 解析线路」选择麒麟、TXNQ、七哥、fongmi、冰豆或 Player-JY，
点击播放。该平台 URL 会被发送给选中的第三方解析站。
「打开已绑定的官方页面」只是打开官方网页，会员和登录由该平台判断，不会开通会员。

目录中选到的某集，也可以在下方展开「平台播放页」，单独绑定你核对过的官方地址，
再交给七条解析线路。**绑定只表示用户自己确认，不表示软件已验证同一作品。**

HLS 解析配置保留，但因先前入口异常证据默认关闭，可在来源设置查看。
没有把任何在线线路标成“开发端已实播通过”。

## 4. 播放状态怎么读

- 生成入口 / 网页加载事件：只代表软件生成 URL 或浏览器触发网页事件，不代表有视频。
- 浏览器报告视频帧与时间推进：直连模式观测到当前视频的帧和时间变化，不是全来源认证。
- 用户确认有画面：你点击了「我已看到视频画面」，记录明确标成用户确认。

第三方网页可能设置禁止内嵌，或依赖被本软件沙箱限制的功能。
黑屏时可换线，或使用「在浏览器中打开」。不要求关闭浏览器安全功能。
外部页面仍可能包含广告或诱导下载，不输入账号密码，不安装其要求的额外插件。

## 5. 本地记录与隐私

默认数据目录：`%LOCALAPPDATA%\YingXia`。
包含 `library.sqlite3`、轮转日志 `app.log` 和专用浏览器配置目录 `browser-profile`。
收藏、逐集绑定与历史记录不会上传。软件不主动读取现有 Chrome/Edge Cookie、账号、密码。
第三方网站在你访问时仍会收到正常网络访问元数据，以及你主动发送的搜索词/播放页地址。

「来源与诊断」可关闭在线访问、关闭后续历史记录保存、切换解析源启用状态，
并导出不含搜索词、媒体链接、账号信息的诊断 JSON。
关闭“保存历史”不会自动删除已有历史；清空记录按钮会要求确认。
网页播放器无法可靠回传秒级进度，因此只记作品/集数和状态；原生媒体可记近似秒级进度。
历史最多保存 300 条，界面展示最近 100 条。

本机 API 设有 Host、Origin、会话 Cookie 和 CSRF 检查；远程播放器只放在受限 iframe 中。
这些措施不是完整安全审计，也不能保证恶意第三方网页或来源未来更新没有风险。
本软件不提供账号共享、DRM 解密或远程 Python 代码自动更新。

## 6. 出问题先看这里

| 情况 | 处理方式 |
|---|---|
| 启动提示没有 Python | 从官方安装 Python，关闭旧命令行窗口后重试 START.bat |
| 浏览器没弹出 | 查看后台 `APP_URL=http://127.0.0.1:...`，手动复制到本机浏览器 |
| 页面显示服务未响应 | 后台窗口可能被关闭，重新运行 START.bat |
| 搜索 DNS / 超时 | 运行连接诊断，比较普通网站对照；检查系统网络和代理，不能直接认定所有来源失效 |
| 平台搜索没有结果 | 该平台可能动态渲染或限制访问；使用官方搜索后粘贴具体播放页 |
| 解析按钮要求绑定 | 当前只有目录媒体地址，没有这一集的官方播放页，先绑定或使用目录播放器 |
| 网页黑屏 | 看真实状态，换线或在独立浏览器打开；不把网页 load 事件当实播成功 |
| 媒体直连格式错误 | 可能是 HLS/编码/跨域/授权限制；改用目录网页播放器，不能靠换 UI 破解授权 |
| 弹出登录或要求安装插件 | 不向第三方提供账号密码，也不按其提示安装未知插件 |
| TLS 证书校验失败 | 检查系统时间、代理证书；不要关闭 TLS 验证 |

日志位于数据目录。诊断报告不含完整平台/媒体链接，便于定位错误。
本版本不承诺 4K/HDR、完整弹幕、第三方播放器自动下一集、全平台自动匹配或长期线路有效。

## 7. 自定义来源与开发

默认配置：`yingxia/sources.json`。
可复制该文件到用户数据目录，修改已知可信的目录/API/解析模板后重启；
此用户配置优先于随包默认配置。模板使用一个 `{url}` 占位符，程序对待转交网址做 URL 编码。
不接受脚本代码或任意命令配置。不要把来源配置指向本机/内网服务。

目录接口需要与常见 VOD JSON 的 `list / vod_id / vod_name / vod_play_from / vod_play_url` 结构兼容；
并非填入任意视频网站首页都能搜索。

运行离线测试：

```bat
py -3 -m unittest discover -s tests -t . -v
```

调试服务（不自动开浏览器）：

```bat
py -3 main.py --no-browser --port 8765
```

UI 自动测试 `tests/browser_smoke.py` 是可选开发测试，额外需要 Playwright。
交付环境有浏览器访问策略限制，因此 UI 测试使用内存装载前端、本机 HTTP 桥和合成目录，
并未关闭管理员策略或将模拟结果声称为真实外部站点结果。详情见 docs/VALIDATION.md。

## 8. 可选：在自己的 Windows 电脑构建 EXE

双击 `BUILD_EXE.bat`。先确认提示，再由本机从 PyPI 下载 PyInstaller 6.22.3 到独立构建环境。
构建输出为 `dist\YingXia\YingXia.exe`，需要保留整个 `dist\YingXia` 文件夹。
**本次交付没有执行 Windows 构建，也不含已验证的 EXE。**
PyInstaller 不是 Windows 交叉编译器，需在目标平台构建。

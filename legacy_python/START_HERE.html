YINGXIA / VERSION 1.0.0

映匣 v1.0
你的本机放映工作台

Python 后台 · Edge / Chrome 应用窗口 · 目录搜索 · 选集与来源切换 · 本地收藏

交付类型：源码运行版，不是免安装 EXE。
需要本机 Python 3.10+；运行时无需额外 pip 依赖。在线片源与 Windows 真机仍未完成实播验收。

三步启动

01 / 完整解压

把压缩包全部解压到普通文件夹。不要直接在压缩包内运行，也不要双击网页源文件。

02 / 检查 Python

需要 Python 3.10+。没有安装时，从 Python 官网安装 64 位版本，并勾选 Add python.exe to PATH。

03 / 双击 START.bat

默认尝试 Edge，其次 Chrome。播放时保留后台窗口；退出时点击软件左下角「退出软件」。

Python 官方下载页：Windows 安装程序。优先 Chrome 可用 START_CHROME.bat。

第一次，先跑离线演示

点击主页「先试试离线演示」→ 第一季 →「播放所选集」。接着试试「下一集」、来源组切换、收藏和最近记录。演示视频是本机合成测试图案，不是影视片源。

测试组故意缺少第 2 集：在第 2 集切换到备用组时，程序应要求你重新选择，而不是自动播放第 1 集。

在线使用：两种入口

方式操作需要知道
目录片名搜索输入片名 → 无损云目录 → 核对候选年份/季数 → 选集 → 目录网页播放器。只接入一条在线目录，不是全网搜索。接口能否返回、播放页能否实播由第三方决定。
按平台定位搜索下拉框选平台，尝试静态入口检索；无结果时打开官方搜索，进入某一集后复制播放页。该检索是实验功能，不保证动态页面、完整选集或准确同名版本。
平台播放页解析右上角粘贴 HTTPS 播放页 → 选择解析线路 → 播放。目录作品也可逐集绑定平台页。七条解析线路需要具体官方播放页，不会把目录媒体地址冒充官方地址。

首次在线使用会提示确认网络访问。目录搜索会发送片名；第三方解析会收到所提供的平台播放页网址。不要在第三方页面输入账号密码或安装未知插件。

状态不是一个「能播」开关

网页加载只代表网页事件；浏览器报告视频帧与时间推进是当前直连媒体的观测；用户确认有画面是你的手动确认。三者分别记录，不会把一个 HTTP 200 当作整条线路已验证。

卡住时怎么处理

没找到 Python：安装后重新运行 START.bat。窗口没打开：复制后台显示的 APP_URL 到本机浏览器。搜索失败：去「来源与诊断」比较网络对照，不把 DNS 错误直接解释为所有来源失效。网页黑屏：换线或在浏览器打开，不关闭浏览器安全功能。

本机数据通常在 %LOCALAPPDATA%\YingXia，日志为 app.log。导出的诊断 JSON 不主动包含片名、完整平台链接或媒体令牌。

可选构建 EXE

BUILD_EXE.bat 会先征求确认，在你的 Windows 电脑下载 PyInstaller 并尝试构建 dist\YingXia\YingXia.exe。必须保留整个 dist\YingXia 文件夹。此构建步骤本次没有在 Windows 执行；日常试用无需先构建。

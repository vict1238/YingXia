# 映匣：三个版本

三个版本均包含“清空记录”修复。清空后会保存到本机，重新打开时记录仍为空；收藏保留。

| 软件 | 使用方式 |
|---|---|
| `YingXia_v1.3.2_Windows_x64.exe` | 原来的独立 Windows 窗口，使用 Microsoft WebView2，保留原界面 |
| `YingXia_v2.0.0_Native_Windows_x64.exe` | 原生 Windows 窗口与播放器，不使用网页渲染内核，保留原来的四页布局 |
| `YingXia_v2.0.0_Android.apk` | Android 8.0 及以上，手机内独立运行，底部导航切换四页 |

Windows 双击对应 EXE 即可。两个 Windows 版本沿用相同的收藏、记录和片源设置，切换版本前请先关闭正在运行的版本。原生版首次启动会释放已校验的运行文件，因此文件较大；不需要安装开发环境。WebView 版需要电脑已有 Microsoft WebView2 Runtime。

Android 将 APK 传到手机安装即可，不需要电脑后台。手机和电脑的收藏、历史分别保存在各自设备上，目前没有自动同步。

原生 Windows 和 Android 使用相同的原生播放器。能够提供媒体地址或静态解析出视频地址的来源可以播放；仅能打开动态网页的来源需要切换到其他片源。WebView 版保留原来的网页播放能力。三版均保留片源管理、来源配置更新、搜索可用性检查与进度。

离开播放工作台或应用进入后台时暂停播放。选集完成后点击“播放所选集”。

应用源码、构建步骤、许可及实际验证证据随源码包提供：WebView 版在 `YingXia_v1.3.2_Windows_x64.zip`，原生 Windows 与 Android 在 `YingXia_v2.0.0_Native_Source.zip`。签名私钥、开发 SDK、用户收藏数据不在源码包中。

两个 Windows 最终 EXE 均已实际运行：WebView 版通过 10 项清空记录检查，原生版通过 10 项窗口、保存和合成播放检查。Android 正式 APK 已在 API 35 x86_64 模拟器安装，完成非空记录的取消、清空、重启持久化及四页运行检查；另编测试后台的同版原生界面完成连续 HLS、WebM 实际画面解码、跨段播放、换集、停止重播、播放结束重播、切页及后台暂停检查。测试 APK 和正式 APK 的 12 个渲染、播放器及 Dart AOT 库逐一比对相同，正式 Go JNI 与发布 AAR 的三个 ABI 比对通过。

实际范围、最终哈希及证据路径记录在 `YingXia_Three_Editions_VALIDATION.json`。Android 真机、16KB 内存页设备运行及全部第三方影片尚未测试。合成解码检查与来源访问检查分别记录。首次测试采用重复时间戳的分段样本时模拟器解码器曾停住，该诊断保留在证据中；最终播放检查采用独立生成、完整解码校验过的连续分段样本。

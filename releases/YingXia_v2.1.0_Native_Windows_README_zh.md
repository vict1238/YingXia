# 映匣 Windows 原生版 2.1.0

运行 `YingXia_v2.1.0_Native_Windows_x64.exe`，无需安装开发工具。启动前关闭旧版映匣。

播放工作台增加“超分”选择，默认轻量：

| 档位 | 处理方式 |
|---|---|
| 关闭 | 播放器正常缩放 |
| 轻量 | 双线性放大与低强度 FSR 1 RCAS 锐化 |
| 增强 | FSR 1 EASU 边缘重建与 RCAS 锐化 |

只在播放区域大于视频尺寸时处理，按实际显示尺寸和比例输出，上限 1920×1080。播放 720p 视频后点击全屏，可查看 1080p 输出。持续渲染掉帧或 GPU 耗时超出预算时，按“增强→轻量→关闭”自动降档；加载、缓冲、暂停和切换尺寸会重新观察。自动降档时界面显示实际档位。影片帧率保持原样。

搜索、播放、收藏与记录、来源与诊断继续采用简洁布局。“来源与诊断”顶部新增开发人员：

- 翻翻蓄小激光 · cqh.vict1238@gmail.com
- 流风驻尘闲 · yuchihaobo@gmail.com

收藏、记录和来源设置沿用 `%LOCALAPPDATA%\YingXia\standalone`；超分选择单独保存在该目录的 `video_quality.json`。

22 项实际窗口检查通过，其中 9 项使用生产后台，13 项使用隔离的合成视频。检查由相同 SHA-256 的软件分批完成，原始报告及合并依据保存在验证记录中。实播覆盖 720p24/30/60、MP4/HLS、三档处理、实际 1080p 纹理、切页 / 最小化暂停及恢复、换集、三轮尺寸与播放操作和退出清理。另有 27 项控制器 / 界面测试、启动器检查及着色器 RGB 校验。

实际显卡为 RTX 4060 Laptop GPU。核显吞吐、较旧 GLES 2 上下文回退和 HDR 运行尚未实测；自动降档通过受控性能数据的控制器测试验证。具体样本、软件和源码哈希见 `YingXia_v2.1.0_Native_Windows_VALIDATION.json`。

本版仅更新 Windows 原生软件。FSR 1 使用 AMD MIT 源码，许可证和原始播放器源码随软件及对应源码包提供。

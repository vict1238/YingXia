# 映匣 Android 2.3.0

软件：`YingXia_v2.3.0_Android.apk`。Android 8.0 及以上；沿用原包名、签名，可覆盖安装。包含 ARM64、ARMv7、x86_64。

本版加入标记广告跳过、提前缓存、卡顿换源提示、收藏与历史断点续播，以及播放区内的音量、倍速、超分、画面比例、快进快退和缓存设置。Android 增加长按画面临时 2 倍速，松开恢复；电视提供启动入口、方向键焦点与大屏控制条。

搜索可输入中文近似片名、完整拼音或首字母；多个匹配片名会显示候选供选择。联想结合本地已见片名与联网片名联想，之后仍按现有流程检查实际来源。换源先核对作品、年份、季数和当前集数，确认后从当前时间继续；临近片尾或已播完的记录从本集开头重播。清空历史同时清除断点，保留收藏。

缓存提供“标准／提前缓存”。卡顿时增加缓冲等待并提示检查其他来源；媒体转发修复固定总时限和长响应截断，分片按需预取、去重和有限重试。前向包缓存 Android 为 48／80 MiB、Windows 为 96／160 MiB，另有 8 MiB 回看缓存与后台 24 MiB 分片缓存；不使用持续增长的磁盘缓存。

超分启动默认仍为关闭，可在来源与诊断设置下次启动的默认值。保留来源管理、测速、88lin／Kazumi 更新、访问检查、收藏、开发人员名单和诊断导出。

广告处理依据 HLS 清单中的明确广告标记，设置中可关闭；未标记或直接烧录在画面中的广告无法保证自动识别。MatePad Pro（Android 16）仍需用此版进行实机持续播放复测。

本版通过 75 项 Flutter 检查与无问题静态分析；后台最新源码在自建 Android 模拟器实际通过 37 项引擎测试、15 个子例和 1 项生命周期测试。Windows 启动器另通过 4 项顶层测试。实际窗口／安装包、失败尝试和设备范围见 `YingXia_v2.3.0_Android_VALIDATION.json`，不把模拟器结果当作 ARM 设备或核显性能测试。

源码与许可：`YingXia_v2.3.0_Android_Source.zip`。Go、Flutter、libmpv、FFmpeg、FSR 与 go-pinyin 的对应源码／许可证和构建说明随源码包保存。发布哈希：`9f0206439131596f03007405e2e19dcadcc39023d1acf5d836de36b2be3e4c3e`。

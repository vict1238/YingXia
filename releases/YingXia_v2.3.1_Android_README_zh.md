# 映匣 v2.3.1 · Android TV 适配测试版

- 电视首页可以用遥控器确定键打开系统键盘，收起后回到输入位置。
- 搜索、选集、播放、全屏和返回支持方向键，返回搜索结果时恢复原焦点。
- 4K 横屏采用电视安全边距、更明显的焦点框和侧边选集布局。

Android 8.0 及以上，支持 ARM64、ARMv7 和 x86_64。可以直接覆盖安装同签名的 2.3.0。

4K Android TV 模拟器通过系统键盘及遥控器流程测试。小米 S75 实机反馈系统键盘仍无法弹出，请在这台电视上使用 [2.3.2 的遥控器输入](https://github.com/vict1238/YingXia/releases/tag/v2.3.2)。
